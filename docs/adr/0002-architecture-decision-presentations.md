# Semantic diagrams and portable PowerPoint animation

The user approved a decision-led narrative, stable native diagrams and grouped click-controlled fly-ins. Use shared JSON models and semantic group names so the same structure can support a complete handout, focused views and an animated explanation. Compose animations from generic PowerPoint-authored timing templates rather than requiring a local PowerPoint installation to author them; verify the resulting file independently in PowerPoint.

C4 serves structural context while the native diagrams explain behavior and consequences. The C4 command accepts a bounded model, generates its own trusted PlantUML and renders locally under SANDBOX. The doctor never installs dependencies: installation source, version and scope must be approved before a separate installation action.
