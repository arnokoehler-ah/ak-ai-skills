# Runtime provenance

The AH palette/logo, conservative Arial text-fit helper and actual-Office preview helper originate in this repository's `ah-business-slides` package at revision `f6bdebf3afde059f97fe0994ef89b45ef162bac9`. They are bundled locally so this skill can be installed alone. Shared fixes should be evaluated in both packages rather than editing only an installed copy.

The native animation behavior templates were authored and played back in Microsoft PowerPoint 16.114, then reduced to generic preset behaviors with placeholder shape/time IDs. The portable composer binds new named groups; it does not copy presentation content or rely on a source deck's numeric IDs. See `assets/animations/README.md`.

The public examples are synthetic. Diagram and presentation inputs are source artifacts; built PPTX/PPSX/PDF/PNG files are reproducible examples, not claims about an actual organization or program.
