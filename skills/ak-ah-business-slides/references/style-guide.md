# AH Business visual language

## Tone and composition

Confident, precise and approachable. One headline makes the point; the body supports it. Use short verb-led headlines, concrete decisions and generous whitespace. Prefer a purposeful three-part composition to a wall of bullet points. Put explanation in speaker notes.

## Tokens

| Token | Value |
|---|---|
| Canvas | 16:9, 13⅓ × 7½ inches |
| AH cyan | `#00ADE6` |
| Deep navy | `#003B67` |
| Secondary text | `#58768B` |
| Pale accent | `#EAF8FE` |
| Base | White |
| Font | Arial, an available cross-platform fallback |
| Cover / title / body | 44 pt / 34 pt / 20–25 pt |

Use the local AH logo with clear space. Brand-colour blocks and a restrained slanted motif add energy to cover slides. Keep data slides calm, aligned and legible. Decorative shapes, lines, cards and charts are native PowerPoint elements. Do not introduce an unrelated dark technology-dashboard aesthetic.

## Narrative repertoire

- Proposal: context → choice → evidence → decision → next step.
- Update: outcome → progress → impediment → request.
- Roadmap: intended change → sequence → ownership → decision points.
- Retrospective: facts → learning → next experiment.

Choose the repertoire that serves the audience. The six-layout example demonstrates visual possibilities, not a mandatory six-slide sequence.

## Visual review

Render the final `.pptx`, inspect each slide at presentation size, and record clipping/overlap, contrast, consistent spacing, chart labels and units, source fidelity and whether the requested decision is explicit. The JSON validator catches density and structural mistakes; it does not measure actual Office font wrapping. Recipients may get different wrapping if Arial is unavailable. Re-render after changing text, images or fonts.
