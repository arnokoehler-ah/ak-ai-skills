# Native entrance-effect templates

These generic PresentationML templates were authored with Microsoft PowerPoint 16.114 and extracted after native playback verification. They contain only animation behaviors and property formulas. Source-specific shape/time IDs are zeroed before storage; there is no presentation content in these files.

The portable composer binds the semantic group target, assigns slide-local time IDs, sets click/with-previous behavior and updates effect duration. Supported entrance effects: Fly In from left/right, Fade and Wipe from left/right. Source group positions stay unchanged in the final state.

Structural verification does not replace playback verification in the recipient's presentation application. PowerPoint is the tested compatibility target; other applications may interpret timing differently.
